## Paw Panel 1.5.0

| 平台 | 安装包 | 系统要求 |
| --- | --- | --- |
| macOS | [下载 macOS 安装包](https://github.com/jdytwagn/Paw-Panel/releases/download/v1.5.0/Paw-Panel-1.5.0-arm64.dmg) | macOS 13+，Apple Silicon |
| Windows | [下载 Windows 安装包](https://github.com/jdytwagn/Paw-Panel/releases/download/v1.5.0/Paw-Panel-1.5.0-windows-x64-setup.exe) | Windows 10/11 x64 |

- 「今日待办」用于每日计划，「管理」用于跨天任务。可手动把长期任务当天要做的步骤写进待办，两页的完成状态独立。
- 点击管理任务的完成圆点，任务划线并移到本组底部。点击行尾 `×` 可删除，并可撤销。
- 管理表格支持底部左右滚动和文字分组开关，编辑任务时可更换或重命名分类。待办的截止时间选择更紧凑。
- 升级时，带旧版管理字段的记录进入「管理」，其余记录按原日期保留。

每个安装包都附带 SHA-256 校验文件。macOS 安装包采用 ad-hoc 签名。Windows 安装包暂无商业代码签名，下载时可能出现 SmartScreen 提示。
